# AI Videos Directory

Place your MP4 video files here.
Example:
- `ai-video-01.mp4` -> Available at `/videos/ai-video-01.mp4`
- `student-copilot-demo.mp4` -> Available at `/videos/student-copilot-demo.mp4`

Supported formats: H.264 compressed MP4 for universal browser playback.
Then update `src/data/aiVideos.ts` to register your video title and category!
